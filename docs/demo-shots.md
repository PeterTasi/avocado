# Demo 素材拍攝清單（截圖 + 一段錄影）

> 上台形式：**用主辦方電腦開我們自己的簡報，6 分鐘**。
> 所以現場不會有即時操作——素材要事先在自己機器上拍好放進簡報。
> 講稿見 `docs/pitch-4min.md`（需擴寫成 6 分鐘版）。

---

## 拍攝前準備

```bash
# 1. 還原乾淨的 demo 資料
./scripts/demo_snapshot.sh restore demo --yes

# 2. 啟動後端
source .venv/bin/activate
uvicorn webapp.main:app --host 127.0.0.1 --port 8000
```

**瀏覽器設定**
- 視窗調成 **16:9**（例如 1600×900），跟投影片比例一致，貼進簡報不用裁切
- 瀏覽器縮放 **100%**（放大會讓字體渲染變糊）
- 用無痕視窗，避免書籤列與擴充功能入鏡

**⚠️ session 閘門（待辦 M，尚未修）**
- **圖譜頁不受影響**——重新整理後直接開就有技能樹，實測過
- **首頁／教材頁／測驗頁受影響**：重新整理後數字會變 0、概念卡會消失
- 所以拍這三頁之前，**一定要先到「教材」頁點一下「線性代數的正交性」**把閘門打開，之後**不要重新整理**

**截圖方式**：`Cmd + Shift + 4` 拖曳選取。Retina 螢幕會存成 2 倍解析度，投影才夠銳利。
（用瀏覽器工具截的圖上限只有 800px 寬，投影會糊，不要用。）

## 錄影：技能樹鏈路亮起（約 5 秒）

這是唯一需要動態的一段——藍色鏈路橫跨整棵樹的效果，截圖傳達不出來。

**操作步驟**
1. 圖譜頁，確認技能樹已顯示、**沒有**任何節點被選取
2. `Cmd + Shift + 5` → 選「**錄製選取部分**」→ 框住技能樹區域（含底部說明框）
3. 開始錄影 → **停 1 秒** → 點 `正交基底` → **停 3 秒**讓動畫跑完、說明框浮現 → 停止
4. 存成 `.mov`，Keynote 與 PowerPoint 都能直接放

**小技巧**
- 錄之前先把滑鼠移到 `正交基底` 附近，減少游標移動的雜訊
- 前後各留 1 秒空白，剪進簡報比較好接
- 錄壞就重錄——這是錄影相對現場操作最大的好處

## ⚠️ 不建議放進簡報的畫面

**複習頁的「通過率 73.9% → 98.0%」**（待辦 L5）

這個數字來自 `pipeline._estimate_pass_probability`，原始碼註解自己寫著
*empirical placeholder, not validated*，而且目前整個資料庫只有 **3 筆作答紀錄**。

**靜態截圖比現場 demo 更危險**——現場一閃而過，但截在投影片上評審可以盯著看、
可以問「3 題怎麼推出 98%？」。

三個選擇：
1. **不要截這一頁**（最安全）
2. 截但**裁掉通過率那三個數字**，只留下方的 FSRS 複習排程
3. 全部放上去，但**準備好誠實的答案**：「這是粗估公式，目前樣本數很少，
   我們展示的是相對排序而非絕對數值」

同理，**班級熱力圖的 `avg_attempts` 是假數字**（`docs/fable5-review.md` #6），
也不要截。
