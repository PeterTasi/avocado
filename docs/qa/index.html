A1掌握度 67% 怎麼算的？三次作答就下結論？
掌握度是排序訊號，不是測量值 —— 它決定我今天先讀哪一個，不是宣稱我學會了幾成。
  • 67% 是 3 次實際作答算出來的，畫面上就寫著「3 次作答」
  • 「0 次作答」跟「答錯很多次」系統分得很清楚，不會混在一起
  • 樣本少我承認 —— 所以我把樣本數印在數字旁邊，讓使用者自己判斷這個數字有多重

A3卡關歸因怎麼決定「根因」？會不會亂猜？
它不是猜。它沿著先修關係往回走，找掌握度最低、而且還沒測驗過的那一個。
  • 例子：正交基底卡住 → 正交集合 → 正交向量 → 內積（0 次作答）
  • 先修關係是從教材抽出來的，不是憑空生成
  • 系統寫的是「最可能的根因」，不是斷言
A4概念圖是 LLM 生的，怎麼確保它不亂編？
三道防線，而且失敗一定告警，絕不靜默套模板假裝成功。
  • 先修邊只能指向同一批抽出來的概念，不能憑空指到不存在的東西
  • 過濾行政雜訊（課程大綱、評分方式那些不是概念）
  • 概念 ID 決定論生成 —— 同一個概念不會分裂成兩個

A5為什麼用 FSRS-5？它是什麼？
它是目前開源間隔重複裡最新、最被驗證的排程模型 —— 不是我自己發明的公式。
  • 每個概念是一張記憶卡片，把我全部作答歷史重放進去，重建記憶穩定度
  • 算出「此刻還記得的機率」，快忘掉又是弱點的排最前面
  • 用現成成熟模型，而不是自己編一個，這件事本身就是可信度
A6手寫辨識準嗎？失敗了怎麼辦？
四層備援，取第一個成功的；四層全失敗就明確告警，絕不假裝成功。
  • 本機 Ollama 視覺 → Chandra → Gemini 原生 PDF → Gemini 逐頁
  • 實測 14 頁手寫約 5 分鐘（我筆電的實測值，不是保證值，密集手寫會更久）
  • 本機跑的好處：離線、不用付費、資料不外傳

A9概念怎麼抽出來的？先修關係怎麼建立？　★ 決賽實問
LLM 讀教材吐出概念，每個概念自己帶一份先修清單，我再把清單轉成邊 —— 不是事後用相似度猜出來的。
  • ① 抽概念：LLM 讀教材，每筆吐出「名稱／章節／說明／先修清單」
  • ② 兩段式過濾：先收集所有要保留的概念名，第二段才處理先修
    — 原本單段過濾會把「先修指向後面才出現的概念」那些邊靜默丟掉，這是我自己發現並修掉的 bug
  • ③ 轉成邊：先修清單 → relation = "prerequisite"，方向永遠是基礎 → 進階
  • ④ 保底：LLM 完全沒給先修時，才退回用章節順序保守推斷
  • 誠實補：我沒有做過人工標註的準確率評估。我的驗證方式是拿課本章節順序對照 —— 內積在正交向量之前，這條鏈是對的
  • 最強的防線是「看得見」 —— 技能樹整張攤在使用者面前，連錯了看得出來，不是黑盒

A10開放式批改有沒有誤判？誤判怎麼處理？　★ 高機率被問
會有。所以我讓它講出理由，而不是只給一個分數 —— 學生看得到推理，就有辦法判斷 AI 是不是錯了。
  • 批改會拆成優點／缺點／改進建議，還會舉反例（附錄 A3 有實際案例）
  • 掌握度是多次作答累積的，單次誤判不會直接毀掉一個概念的狀態
  • 誠實補：我沒有做過批改準確率的統計，目前是 3 筆真實作答
  • 這跟我第 11 頁講的誠實原則是同一件事 —— AI 可以錯，但要讓人看得出來它錯了

A11上傳好幾門課，技能樹會不會變得很雜亂？　★ 決賽實問（評審誤會這裡）
不會。技能樹一次只顯示一門課。我目前有 4 門課，但畫面上永遠只畫你切到的那一門。

  • 要舉例就講：4 門課 63 個概念，但技能樹上只會看到那一門的 13 個

B2跟 NotebookLM 的心智圖差在哪？
心智圖畫的是「這個屬於那個」；技能樹畫的是「我要先會什麼，才學得動這個」。

  • 它記得我的資料，但不記得我；我的系統記得我學到哪裡

B3間隔重複 Anki 早就有了，你差在哪？
Anki 要我自己建卡片；AdaptLearn 是從我的教材自己長出卡片，而且會往回追根因。
  • Anki 卡片人工建；我的是從講義／投影片／手寫筆記自動抽概念
  • Anki 排的是卡片；我排的是概念，而且概念之間有先修關係
  • 所以 Anki 只能告訴我「這張卡該複習了」，我的能告訴我「你卡住是因為三層前的內積」
  • 排程一樣用 FSRS-5，但決定「排什麼」的邏輯完全不同
B4可汗、均一那些平台不是也有知識地圖？
他們的地圖是官方預先建好的；我的是從學生自己的教材長出來的。

  • 所以它對得上這一堂課的進度，不是通用課綱
  • 換一門課、換一個老師，重新丟一次就好
